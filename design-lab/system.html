The tonal ladder

Nine surfaces, and the step between them is a measured perceptual quantum, not a taste. Hue and chroma are held constant, so only lightness moves — which is what makes it a scale rather than a palette. The previous hand-made ladder wandered 14° in hue and varied 2.3× in chroma.

The directional rim

A 180° linear gradient that fakes a light source above. Top is 100%, side 55%, bottom is the lowest ladder step. It is what makes a surface read as lifted rather than merely lighter.

top = ladder(host + 1)  |  side = ladder(host + 0.5)  |  bottom = ladder(host)
tiertop (100%)side (55%)bottomwhere

On press, the gradient inverts to 180° reversed and the element moves down translateY(0.5px) — the surface reads as physically pushed in.

Borders

A border is not a colour. It is the ladder step one half above its host, so it is always exactly as visible as the surface it sits on — never more, never less.

border(role, kind) = ladder(host + 0.5)   clamped to the ceiling
kindon the work surfaceon a menuwidthwhat it means
hairline #0a0c0e #101215 1px the thinnest line the system draws — a seam, not a wall
edge #0b0d0f #111316 2px a boundary that should be seen — an input, a focused control

The clamp matters: without it, a border on the ceiling surface would ask for a ladder step that does not exist and silently return the ceiling itself.

Text hierarchy

Four levels, and the alpha of each is derived from a declared-use floor rather than picked. Both lenses are applied — APCA and WCAG — and the stricter one wins. There is no code path that returns a colour which fails its floor.

alpha = the smallest value where APCA ≥ Lc floor and WCAG ≥ ratio floor
rolerenderedvaluealphaAPCA floorWCAG floordeclared use

secondary The quick brown fox rgba(255, 255, 255, 0.79) 0.790 Lc 75 4.5:1 body-minimum
tertiary The quick brown fox rgba(255, 255, 255, 0.79) 0.790 Lc 75 4.5:1 body-minimum
quaternary The quick brown fox rgba(255, 255, 255, 0.44) 0.440 Lc 30 3:1 text-minimum

secondary and tertiary share an alpha (0.790). Their hierarchy is size and weight, not colour — the honest reading of a shared floor, chosen by eye from a live test.

quaternary is not for read copy. Its floor is APCA Lc 30 — the minimum for any text — and it measures 4.06:1 on the darkest surface, under the 4.5 AA asks for normal text. Its legitimate uses are placeholders, disabled text and decorative separators.

Semantic roles

Four roles. Only the hue is a convention — everything else is derived: the fill's lightness from the APCA floor against white text, the chroma from one value shared by all four, the text colour from the same dual-lens derivation as the text hierarchy.

Mist

The surface treatment for floating elements. It is derived from float height — the further a surface is from the canvas, the more fog it collects. There is no blur: ⁨backdrop-filter⁩ was measured at 35.7× the compositing cost for no visible gain on near-uniform dark.
