۰۲سه گزینه، سه عرض واقعی

هر ستون یک iframe با عرض واقعی است. داخل هر iframe واحد vw واقعی است، پس clamp() دقیقاً همان‌طور رفتار می‌کند که در مرورگر واقعی رفتار می‌کند.

۰۵Container query — چیزی که media query نمی‌بیند

یک کارت، دو ظرف، یک viewport. Media query هر دو را یکسان می‌بیند چون عرض صفحه یکی است. Container query هر کدام را جدا می‌بیند چون به عرض خودش نگاه می‌کند.

افقی
.liminal-card { container-type: inline-size; }
@container (min-width: 340px) {
  .liminal-card__inner { flex-direction: row; }   /* فقط وقتی خودِ کارت جا دارد */
}

در همین صفحه هر دو کارت داخل یک viewport هستند. Media query نمی‌تواند این تفاوت را ببیند.
