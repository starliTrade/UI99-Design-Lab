نقطه‌های شکست مشتق‌شده — زنده

اسلایدر را بکش. هر نقطه‌ی شکست از عرض خودِ محتوا مشتق شده، نه از دسته‌بندی دستگاه. اعداد از LiminalLayoutEngine.BREAKPOINTS خوانده می‌شوند، و هر نمونه یک کامپوننت واقعی داخل یک viewport واقعی است — چون هر مکانیزم به چیز متفاوتی جواب می‌دهد: container query به جعبه‌ی خودش · media query به viewport · vw به viewport.

۱ — گرید container query

gridWide = 12 × CELL_MIN(64) + 11 × SPACING[4](16) = 944px gridMid = 6 × CELL_MIN(64) + 5 × SPACING[4](16) = 464px دوازده خانه در کفِ خودشان جا می‌شوند؛ یک پیکسل کمتر، خانه‌ها زیر کف فشرده می‌شوند.

۲ — ردیف فرم container query

formRow = 2 × FIELD_MIN(200) + SPACING[5](24) = 424px دو فیلد کنار هم، به‌علاوه‌ی فاصله‌ی بینشان. زیر این عرض، ردیف تک‌ستونه می‌شود.

۳ — پوسته و سایدبار media query

shellSidebar = SIDEBAR_W(220) + SPACING[5](24) + MEASURE_MIN(360) + 2 × SPACING[5](24) = 652px سایدبار + فاصله + یک ستون خوانا + پدینگ بدنه. ناوبری موبایل همان عرض را دارد — چون همان رویداد است. جفت قدیمی (۸۰۰ / ۶۴۰) نواری می‌ساخت که در آن نه سایدبار بود نه ناوبری.

۴ — برد اصلی: container query در برابر media query

یک گرید ۱۲ستونه داخل یک سایدبار 220px، روی یک viewport پهن. هر دو قاب عرض یکسان دارند — تفاوت فقط در این است که گرید به چه چیزی گوش می‌دهد.

media query — رفتار قبل از Step 2.2 · viewport 1100px

می‌شکند viewport پهن است، پس @media (max-width: 944px) هرگز شلیک نمی‌شود؛ گرید ۱۲ستونه در 220px فشرده می‌ماند.

container query — رفتار Step 2.2 · همان viewport

درست گرید به عرض 220px خودش گوش می‌دهد و جمع می‌شود — هرچقدر هم viewport پهن باشد.

۵ — شاهد: مرز دقیقاً کجاست؟

ادعای مشتق این است: در نقطه، چیدمان دقیقاً روی کف خودش جا می‌شود؛ یک پیکسل کمتر، فشرده می‌شود. پس باید در BP هنوز چیدمان کامل باشد و در BP − 1 بشکند.

هر ردیف سه قاب دارد: یک پیکسل پایین‌تر، روی نقطه، یک پیکسل بالاتر.

gridMid = 464px

gridWide = 944px

formRow = 424px

۶ — مقیاس نوع شناور

TYPE_RATIO = 1.2 · TYPE_BASE_LEVEL = 3 TYPE_BASE_CSS = clamp(0.875rem, 0.2232vw + 0.8304rem, 1.03125rem)

ستون سوم با var(--liminal-fs-N) رندر می‌شود (شناور)، ستون چهارم با همان px ثابتی که کامپوننت‌ها الان استفاده می‌کنند. اگر با هم جلو نمی‌روند، یعنی شناور وصل نشده.
