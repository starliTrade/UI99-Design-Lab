## فایل‌های اصلی

- `LIMINAL-POLICY-B.md`: سیاست نسخهٔ ۲ (بوم، لایه‌ها، مرز، ریم، سایه، حالت‌ها، تودرتو، نور).
- `src/engine/liminal-ladder-b.ts`: موتور نردبان.
- `src/engine/__tests__/ladder-b.test.ts`: تست‌های سیاست.
- `design-lab/LADDER-DECISIONS.md`: تصمیم‌ها با تاریخ و آزمون.
- `design-lab/ladder-b-*.html`: صفحه‌های آزمون چشمی (منتشر شده روی GitHub Pages).
